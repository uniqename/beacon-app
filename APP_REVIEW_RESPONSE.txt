GUIDELINE 2.3 — Live Audio Support Circles Feature
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

The live audio support circles feature IS fully implemented in the app.
We identified and fixed a bug where the "Create Room" button was hidden from
Survivor accounts — it was only shown to counselors/admins. In this build,
any registered Survivor can now create and host a peer support circle.

HOW TO ACCESS THE FEATURE:

Step 1: Create a new account (or use demo account)
  Demo:  reviewer@beaconnewbeginnings.org / SafeReview2025!
  OR: Tap "Get Started" → select "Survivor" → any email + 6+ char password

Step 2: Navigate to Community tab (3rd icon in bottom navigation bar)

Step 3: Tap the "Support Groups" tab

Step 4: Tap the orange "Create Room" button (bottom right corner)
  - Enter a room name and tap "Create"
  - You will immediately enter the live audio room

Step 5: Inside the audio room you can:
  - Speak (tap microphone button to unmute)
  - See other participants listed as Audience or Speakers
  - Raise hand to request speaking permission
  - Leave by tapping the exit button

The audio room features:
  - Real-time voice communication (Agora SDK)
  - Speaker/audience/moderator roles
  - Raise-hand feature to request speaking permission
  - Survivor-led peer support circles (fixed in this build)

NOTE: The app description calls these "support circles" — in-app they appear
as "Live Rooms" within the Support Groups section. This is the same feature.
